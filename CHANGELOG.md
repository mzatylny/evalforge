# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and semantic
versioning.

## [1.0.0] - 2026-08-11

### Added

- Provider-neutral normalized trace and scenario contracts.
- Deterministic multi-signal evaluation with explainable failure codes.
- Matched baseline/candidate analysis with a seeded bootstrap confidence interval.
- Policy-as-code release gates for quality, safety, sample size, latency, and cost.
- FastAPI control plane, responsive dashboard, health/readiness, and Prometheus metrics.
- Tenant-isolated SQLite evidence store with a tamper-evident audit chain.
- Deterministic 40-scenario portfolio demo and failure-reduction utility.
- CI, coverage gate, Bandit, dependency auditing, CodeQL, container build, and Dependabot.
